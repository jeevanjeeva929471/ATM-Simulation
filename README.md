# ATM Simulation System in Python 🏦

## Description
This is a simple console-based ATM machine simulation built using Python Object-Oriented Programming (OOP). It demonstrates basic banking operations with PIN validation and security limits.

## Features
* **PIN Validation:** Requires a 4-digit PIN (Default: 1234).
* **Security:** Maximum 3 incorrect attempts allowed before locking.
* **Account Balance Check:** View real-time available balance.
* **Cash Withdrawal:** Checks for sufficient balance before deduction.
* **Cash Deposit:** Adds money directly to the account balance.

## How to Run
1. Ensure Python is installed on your Windows PC.
2. Run the file using the command: `python atm.py`
3. Enter the default PIN `1234` to test the operations.
